

## 對應歐美目前實施的Consent要求，快速設定Consent 訊號範本。
發送Google Consent API，藉此調整網站的使用者同意模式徵求，支援推送DataLayer, 自訂區域。

## 使用步驟
將tpl下載下來，或直接至GTM的範本頁面搜尋 - Consent Mode API 中文化範本
(因GOOGLE審核較緩慢，如搜尋不到請手動下載，再直接匯入至GTM。此為黑客數位提供，無植入功能以外程式碼，請放心使用。)


在GTM的"範本選單 點選新增(new)，並點選右上角的選單，再點選匯入，選擇下載好的tpl檔即可完成!


後續在GTM的代碼選單裡面，即可開始使用，輕鬆調整網站 Consent模式。
